## 오늘의 구조

| 챕터 | 하는 일 | 산출물 |
|---|---|---|
| 0 | 앞장 — 오늘은 책을 만들지 않는다 | 이름·교과 |
| 1 | 두 번 쓴 하루 — 「낙서」와 「알맞은 시절」 | 표현 방법 여섯 + 세 문단(줄거리·공통점·차이점) |
| 2 | 오늘 가져갈 것 — 가는 길·본 것·남은 생각 / 짧게·길게·다른 눈으로 | 대조 칸 + 우리 반 한 줄 |
| 3 | 다른 눈으로 — 시점 전환 릴레이 사례 | 나를 보고 있었을 쪽 하나 |
| 4 | 글 설계 — 아홉 칸 + 여덟 칸 카드 | **내 글 설계 카드** |

| 6 | 수업 한 줄 | 전이 한 줄 |

## 읽기 순서 (설계상 고정)

**짧은 쪽(「낙서」) → 표현 방법 여섯 가지 분석 → 긴 쪽(「알맞은 시절」).**
긴 쪽을 먼저 보여 주면 얻을 것이 절반으로 줄어듭니다. 챕터 1의 `details`가 닫혀 있는 것은 의도입니다.
